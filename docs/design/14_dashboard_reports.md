# 14 ダッシュボード・帳票・現在状況

版1.0 / 2026-10-23。画面の金額は同じ会計snapshotから計算し、処理途中の数値を混在させない。

## 1. ホームで分かること

期間、年度、会計方式、基準日時、ledger_revisionを表示する。月次/年次の売上、費用、利益、現預金、未回収、カード未払、資料不足、未確定仕訳、cloud未同期、申告作業を確認できる。

「今いくらあるか」「売上はいくらか」「確定申告を進められるか」は異なる指標。銀行残高と利益を同じ数字として表示しない。

## 2. 指標の定義

| 指標 | 定義・範囲 |
|---|---|
| 売上高 | 対象期間のposted売上関連科目の純額 |
| 費用 | 対象期間のposted費用、返品/訂正を反映 |
| 帳簿利益 | 収益−費用。青色申告特別控除前の帳簿値 |
| 現預金 | 指定as_ofの帳簿残高。外部残高は別表示 |
| 未回収 | as_of時点open item元本−有効割当 |
| カード未払 | 確定利用・返金・精算等による帳簿債務 |
| 仮集計 | 未確定候補を参考表示したもの。確定値へ加算しない |
| 申告概算 | 税務属性/他所得/控除の入力範囲とrule版を明示した試算 |
| 取込完全性 | account×資料種別×期間のcoverage |
| 証憑不足 | 根拠なし、索引不備、未確認、未同期を別集計 |

消費税の申告方式や適用条件が未設定なら単一の納税予測を確定値風に出さない。会計利益から直接所得税を定率で求めない。

## 3. 主要画面

月次P/Lは売上元別・費用科目別にdrill-down可能。クリックすると対象posted伝票へ移動し、さらに元明細・証憑へ辿れる。サービス売上とサービスからの入金を別系列で表示する。

資金画面は現預金・予定引落・未回収を表示する。予定は実績と色/ラベルで分け、取得日時と確度を示す。AI推測の入金予定を確定債権として計上しない。

異常一覧は未処理件数だけでなく、対象期間、影響金額、根拠、担当操作を表示する。高severityから並べても、利用者が対象口座/年月で絞れるようにする。

## 4. 時点残高

open itemは年度をまたぐ同一ID。opening仕訳は残高投影のため、新しい債権として加算しない。as_ofには業務日条件を使い、凍結資料は記録上限/入力ID集合も固定する。

後日取消を登録しても、取消効力日より前の未回収一覧を変えない。過去snapshotはその作成時点の固定集合で再現する。現在の完済フラグから過去年末残を再計算しない。

## 5. 申告準備の進捗

各工程を未着手/要確認/完了/未対応として表示する。必須工程のblockerを率で平均して隠さない。99%でも未対応の申告様式があれば提出準備完了にはしない。

工程は資料取得、記帳、残高照合、証憑、決算整理、他所得/控除、年度rule、申告書、e-Tax署名/送信、受付、納付。各工程の判定根拠と最終点検時刻を持つ。

AIは不足の理由と次の作業を説明する。決定的検査のblockerをAIの「問題なし」で解除しない。帳簿revisionが変わると前回reviewをstaleとする。

## 6. 帳票出力

仕訳帳、元帳、補助元帳、試算表、P/L、B/S、未回収/未払、サービス精算、証憑一覧、申告転記ガイドをCSV/PDFで出す。

出力物に対象期間、基準日、作成時刻、revision、rule/profile版、未確定の含有有無を付記する。PDFとCSVは同じデータ集合を使う。端数・合計・ページ跨ぎ・日本語fontを検証する。

CSVはUTF-8/UTF-8 BOMを選択でき、表計算向け数式注入を防ぐ。元資料を上書きせず、15章のexport root/no-clobber規則を使う。

## 7. 再現とキャッシュ

cache keyはorg、年度、期間、as_of、ledger_revision、対象科目、rule版、記録境界を含む。確定、訂正、消込、繰越差額で関連cacheを失効する。

金額と件数は単一read snapshotで取得する。長い集計はprogress/cancelを提供し、結果に基準revisionを付ける。処理中に帳簿が変わった場合は新規再計算を案内し、異なるrevisionのwidgetを無表示で混在させない。

## 8. 受入条件

試算表の借貸一致、P/Lと申告基礎資料の照合、年跨ぎ未回収、後日取消、カード引落し、複数サービス精算、snapshot再現、CSV/PDF一致、未取得期間があるのに完了としないことを確認する。

税務計算の根拠は11章、e-Tax進捗は12章、証憑条件は13章に従う。本章のUI・cache・指標表示は独自設計。
